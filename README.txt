LayerExplode v1.0.2
工艺图层爆炸示意图 · Windows 离线工具

【使用方法】
1. 把正面原图、工艺图、可选的背面图放进一个素材文件夹。
2. 将素材文件夹拖到 Main.bat 上；或者双击 Main.bat，选择素材目录。
3. 如果没有 Layers.txt，脚本会自动生成并打开。调整行顺序和显示文字，保存。
4. 再次运行 Main.bat，得到素材目录中的 Exploded_Layers.png（3840×3840、1:1、透明背景）。

【Layers.txt 示例】
香味油墨.png | 香味油墨
冷烫幻彩.png | 冷烫幻彩
逆向光油.png | 逆向&光油
白墨.png | 白墨
> 正面.jpg | 原图
背面.jpg | 背面

- 从上到下就是成品的从上到下；每行左边是素材文件名，右边是显示文字，以 | 分隔。
- 以 > 开头的一行是主图层（正面原图），其画面长宽比是所有卡面的基准。
- 主图层上方是半透明工艺层；主图层及其下方都是完整、常规不透明的卡面。
- 新建 TXT 时，程序自动在最后一行放 >。若有背面，将 > 剪切到倒数第二行即可。
- 如果 TXT 原来没有 >，仍以最后一行为主图层；旧版 -> 标记也兼容，不必重做 TXT。
- 如果文件名与显示文字一致，可只写文件名；要隐藏左侧文字，写“文件名 | ”。
- 空行和以 # 开头的行会被忽略；主图层标记只能出现一次。

【图片规则】
- 支持 PNG、JPG、JPEG；无需预先统一图片像素尺寸。
- 所有图片按照主图层的画面比例，执行居中等比填充（cover），多出部分自动裁掉。
- 工艺层采用自下而上的 Alpha 叠加：上层优先呈现，下层在交叠区被明显减弱；仍然可以透过上层看见下层。
- 工艺层有一张浅淡的半透明薄片底板，并在板片边缘加极细分界线，辅助辨认上下关系。
- 工艺层整体图像不透明度为 68%，薄片底板另有约 26% 的 Alpha；PNG 原有透明度会被保留并相乘。
- 主图层及背面不降低透明度；输入 PNG 若原本带透明像素，仍然保留这些透明像素。
- 不抠图、不加整体背景。成品画布以完全透明 PNG 交付设计师继续加工。

【注意事项】
- 只有写进 Layers.txt 的图片才参与合成；源文件与 TXT 都不会被脚本修改。
- 再次运行会覆盖上次生成的 Exploded_Layers.png。
- 工艺图是截图时，自动居中裁切只对齐截图外框，不会智能校正截图本身的偏移。
- 多层或长标签可能变得拥挤，属于自动排版当前版本的限制。
- Windows 10/11 + Windows PowerShell 5.1，使用系统自带功能，无需 Python 或安装其它软件。
- 可将 Example 文件夹直接拖到 Main.bat 上试运行。
