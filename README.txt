LayerExplode v1.0.1
工艺图层爆炸示意图 · Windows 离线工具

用法
1. 将所有正面海报、工艺图层、以及可选的背面图片放进同一个文件夹。
2. 双击 Main.bat，选择该素材文件夹；也可以直接把素材文件夹拖到 Main.bat 上。
3. 如果文件夹中没有 Layers.txt，程序会自动创建并用记事本打开。调整图层顺序，保存后再次运行 Main.bat。
4. 程序在素材文件夹内生成 Exploded_Layers.png（3840×3840，1:1，透明背景）。

Layers.txt 写法
每一行：图片文件名 | 左侧显示文字
若要指定“主图层”，就在该行最前面加 ->
例如：
Fragrance.png | 香味油墨
ColdFoil.png | 冷烫幻彩
SpotUV.png | 逆向&光油
White.png | 白墨
-> Front.jpg | 正面
Back.jpg | 背面

规则说明
- 从第一行到最后一行，就是成品从最上面到最下面。
- 带 -> 的那一行是主图层：它决定基准长宽比，也是“正面分层结构”的底层。
- 主图层上方的行：按工艺分层处理，统一半透明，并带极淡的悬浮板片。
- 主图层本身及其下方的行：按整张卡面处理，保持不透明。最常见就是最后一行作为背面。
- 如果没有 ->，则默认最后一行是主图层，也就等于没有背面。
- 如果文件名已经能代表标签，可只写文件名，程序会自动使用去掉扩展名的文件名作为文字。
- 某行要隐藏标签，可写“文件名 | ”（竖线后留空）。空行和 # 开头的说明行会被忽略。

素材要求
- 支持 PNG、JPG、JPEG；文件放在同一个目录。
- 主图层应是完整卡面，并作为全部图片的基准比例。
- 上层工艺图层允许尺寸不同、分辨率不同、截图不精确；程序会按主图层比例，对每张图执行“居中、等比放大、直到完全铺满”的 cover 处理，并裁掉超出的边缘。
- PNG 的原始透明区域会被保留；工艺层的原始 Alpha 会再乘以 46%。
- JPG 作为工艺层时，包括背景在内的整张图片都会变成半透明。
- 为了让透明工艺 PNG 也呈现完整悬浮薄片，每个工艺层会加一层极淡的半透明板片；整体画布仍然完全透明。
- 不自动抠白底、不加背景或其它美术装饰。透明背景里仅绘制图层结构及左侧标签。

本版改进（相对 v0.0.2）
- 画布由 16:9 改为 1:1。
- 图层间距明显加大，只保留局部重叠，更利于参考。
- 左侧文字改为更靠近图层，并采用靠近图层边缘的右对齐方式。
- 新增主图层标记 -> ，从而支持“正面分层 + 背面单张”的常见结构。

注意
- 脚本不会修改源图片或 Layers.txt。
- 目录中没写在 Layers.txt 里的图片不会参与合成。
- 再次运行会覆盖上次生成的 Exploded_Layers.png。
- 仅支持 Windows 10/11 内置的 Windows PowerShell 5.1，且应运行 64 位 powershell.exe。
- 如果标签或图层数过多，画面仍可能比较密集；v1.0.1 仍是最小可行模型，暂不提供 GUI 几何调参。
- 可以直接使用随包 Example 文件夹测试：将该文件夹拖到 Main.bat。
