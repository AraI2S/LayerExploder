LayerExplode v1.1.1
工艺图层爆炸示意图 · Windows 离线工具

【推荐的使用流程】
1. 把正面原图、工艺图以及可选的背面图，放进本工具旁边的 i 文件夹。
2. 双击 Main.bat。按一次回车，直接使用 i；想选择其它素材目录就按一次空格。
3. 如果目录里没有 Layers.txt，程序会自动生成清单并打开编辑窗口。
   调整图层顺序、文字、主图层 > 标记后，点击“保存并继续”，或直接关闭窗口。
   编辑窗口关闭会自动保存真实的 Layers.txt，脚本随即继续生成，不必再次运行。
4. 如果已经有 Layers.txt，控制台会预览其有效行。按一次回车直接生成；
   按一次空格打开编辑窗口，修改并关闭后会按最新内容生成。
5. 默认使用 i 时，成品输出在工具主目录，与 Main.bat 同级：Exploded_Layers.png。
   手动选择其它文件夹时，成品仍输出在所选素材文件夹内。
   统一为 3840×3840、1:1、透明背景 PNG。

说明：弹出的编辑器是 LayerExplode 用 Windows Forms（WinForms）控件创建的轻量编辑窗口，
不是 Windows 记事本，也不是需要单独安装的第三方程序。它运行于 Windows PowerShell 5.1
与 .NET Framework 中，可用于 Windows 10/11 的常规桌面环境。支持 Ctrl+S 和关闭时自动保存。
它只编辑真正的 Layers.txt，并在窗口关闭后继续执行，不受新版记事本多标签页行为影响。

【其它选择方式】
- 也可以把任意素材文件夹拖到 Main.bat 上：直接使用该目录，再进入清单预览/编辑流程。
- 如果 i 不存在，工具会自动创建。若 i 没有图片，先放入素材再运行，或使用空格选择其它目录。
- i 是用户素材目录，可以长期保留和更换素材；每次仅修改清单或图片即可。
- 将 i 文件夹拖到 Main.bat 上同样视作默认 i，成品输出在工具主目录。
- 如果你从旧版升级，i 中以前生成的旧 Exploded_Layers.png 不会自动移动或删除；新成品在主目录。

【Layers.txt 示例】
香味油墨.png | 香味油墨
冷烫幻彩.png | 冷烫幻彩
逆向光油.png | 逆向&光油
白墨.png | 白墨
> 正面.jpg | 原图
背面.jpg | 背面

- 从上到下就是成品的从上到下；每行左边是素材文件名，右边是显示文字，以 | 分隔。
- 以 > 开头的一行是主图层（正面原图），其画面比例是所有卡面的基准。
- 主图层上方是半透明工艺层；主图层及其下方都是完整的常规卡面。
- 新建 TXT 时，自动在最后一行放 >；如果有背面，将 > 移到正面原图那行。
- 不带 > 时默认最后一行为主图层；旧版 -> 标记仍然兼容。
- 文件名和显示文字相同时可以只写文件名；要隐藏标签写“文件名 | ”即可。
- 空行和 # 开头的行会被忽略；只能标记一个主图层。

【图片与合成规则】
- 支持 PNG、JPG、JPEG；图片尺寸可以不同。
- 所有图层以主图层为基准，居中等比填充并裁掉超出的边缘。
- 工艺图使用自下而上的 Alpha 合成，层间上下关系清晰，附极淡薄片底板和细轮廓。
- 仅图层及对应标签可见；透明背景可交给设计师后续添加美术元素。
- 输入图片、TXT 都不会被渲染器改动（仅在编辑窗口中由你主动修改 TXT）。
- 不在 Layers.txt 中列出的图片不参与合成；再次生成覆盖旧成品。

【运行环境】
Windows 10/11，使用系统自带 Windows PowerShell 5.1、WinForms 和 System.Drawing。
无需安装 Python、Photoshop 或其它软件。

- 其它绘图与图层信息编辑行为不变。
