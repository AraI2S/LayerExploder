LayerExplode v0.0.2
工艺图层爆炸示意图 · Windows 离线工具

用法
1. 将所有正面海报和工艺图层的 PNG/JPG 图片放进一个文件夹。
2. 双击 Main.bat，选择该素材文件夹；也可以直接把素材文件夹拖到 Main.bat 上。
3. 如果文件夹中没有 Layers.txt，程序会自动创建并用记事本打开。调整图层顺序，编辑文字，保存后再次运行 Main.bat。
4. 程序在素材文件夹内生成 Exploded_Layers.png（3840×2160，16:9，透明背景）。

Layers.txt 写法
每一行：图片文件名 | 左侧显示文字
例如：
UV.png | 立体UV
Foil.png | 金属烫印
White_Ink.png | 白墨层
Poster.jpg | 正面海报

从第一行到最后一行，就是成品从最高层到最低层。最后一行自动视为底图，并决定所有图层的基准长宽比；其它行统一设置为半透明（46%）。
如果文件名已经能代表标签，可只写文件名，程序会自动使用去掉扩展名的文件名作为文字。
某行要隐藏标签，可写“文件名 | ”（竖线后留空）。空行和 # 开头的说明行会被忽略。

素材要求
- 支持 PNG、JPG、JPEG；文件放在同一个目录。
- 底图（Layers.txt 最后一行）应是完整正面海报，并作为全部图层的基准比例。
- 上层工艺图层允许尺寸不同、分辨率不同、截图不精确；程序会按底图比例，对每张图执行“居中、等比放大、直到完全铺满”的 cover 处理，并裁掉超出的边缘。
- PNG 的原始透明区域会被保留；其它工艺层的原始 Alpha 会再乘以 46%。
- JPG 作为工艺层时，包括背景在内的整张图片都会变成半透明。
- 为了让透明工艺 PNG 也呈现完整悬浮薄片，每个工艺层会加一层极淡的半透明板片；整体画布仍然完全透明。
- 不自动抠白底、不加背景或其它美术装饰。透明背景里仅绘制图层结构及左侧标签。
- 文本标签默认浅色，以适用于设计师进一步叠加暗色背景。

注意
- 脚本不会修改源图片或 Layers.txt。
- 目录中没写在 Layers.txt 里的图片不会参与合成。
- 再次运行会覆盖上次生成的 Exploded_Layers.png。
- 仅支持 Windows 10/11 内置的 Windows PowerShell 5.1，且应运行 64 位 powershell.exe。
- 如果标签或图层数过多，画面可能较密集；v0.0.2 仍是最小可行模型，暂不提供 GUI 几何调参。
- 可以直接使用随包 Example 文件夹测试：将该文件夹拖到 Main.bat。
